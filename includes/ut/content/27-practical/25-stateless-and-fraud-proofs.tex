\subsubsection{Stateless Full Nodes and Fraud Proofs}

A stateless full node (aka. a stateless client) is a node that verifies all blocks, but does not actively track the current state of the chain.
Instead, a stateless full node will use some minimal \emph{witness} data (specific to each block) to verify that the state transition was valid.
This is possible because \emph{most} of the state tree remains untouched.
The mutations to the state tree made by a block's transactions are all calculable from the witness data and the transactions, alone.
In other words: the prior state root, the witness data, and the full block are all that is required to calculate the output state root of that block.

\aside{
    We won't discuss the general idea of stateless nodes here, since there are many existing resources\footnotemark{} on the topic.
    Note that some stateless node designs require that each individual \emph{transaction} include appropriate witnesses, rather than each block having a combined witness.\\
    \\
    Although we will design a method that supports transaction witnesses, we won't require that transactions include them.
}
